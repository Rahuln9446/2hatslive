## Notes on Design Implementation

- While reviewing the Figma design files, I encountered limited access to Dev Mode, which restricted visibility into detailed properties such as exact spacing, sizing, and CSS values.
- Additionally, some layers did not display their full properties or styles, which may have led to slight differences in dimensions or positioning.

## Font Substitution

- The original design specified the use of **Proxima Nova**, which is a licensed font and not freely available for development use.
- To maintain consistency with the overall look and feel, I used **Montserrat**, a free and open-source font that closely resembles Proxima Nova in style and proportions.
